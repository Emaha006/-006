# Мықты бол

Сайт для профилактики лудомании среди молодёжи. Проект для конкурса «Идея против зависимости».

Один файл `index.html`, без сборки и зависимостей (шрифт Inter подключается с Google Fonts).

## Запуск
Откройте `index.html` в браузере.

## Публикация на Vercel
Импортируйте репозиторий на vercel.com, настройки по умолчанию (Framework Preset: Other, без команды сборки).
